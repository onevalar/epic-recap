Epic Recap 0.3.0 — 商店隐私字段填写依据
检查日期：2026-10-29。以本次代码和上传包为准；不能把“仅本地”写成“不处理用户数据”。

Single purpose / 单一用途
在用户启动的网页问题记录会话中，收集复现步骤及相关诊断信息，并经用户检查后导出本地问题报告，帮助排查网页故障。

权限理由（可分别复制到后台）
scripting：在用户选定标签页及其子框架中启动、停止和读取页面诊断采集器，获取普通隔离脚本无法访问的页面 JavaScript 请求、日志及错误信息。
tabs：显示可选择的标签页标题与网址，维护最多 4 个页面的记录会话，并处理标签页切换、导航和关闭。
downloads：将用户确认后的报告与附件下载为本地 ZIP，并检查下载状态、提供打开下载所在目录的操作。
activeTab：支持用户点击扩展或快捷键后，对当前页面进行截图及用户主动发起的诊断操作；不会凭此权限自动启动记录。
storage：在本地保存用户设置、记录会话、草稿、诊断事件和恢复信息；不使用 Chrome 同步存储上传记录。
unlimitedStorage：用户主动记录的截图、较大的诊断数据和可选视频可能超过默认本地配额；用于本地保存和恢复，不用于远程同步。
alarms：执行手动记录的 10 分钟停止限制、持续记录的 5 分钟切段以及记录检查点保存。
webRequest：收集正在记录的标签页的网络请求时间、状态、失败原因和必要响应信息，辅助复现网络故障；未启动记录的标签页不会写入诊断记录。
system.cpu：在记录期间采样 CPU 使用情况和处理器信息，帮助区分网页卡顿与设备资源瓶颈。
system.memory：在记录期间获取设备内存容量和可用量，作为网页性能问题的诊断上下文。
tabCapture：用户选择可选视频并授权标签页后，录制该标签页的画面及页面声音；不采集摄像头或麦克风。
offscreen：提供 Manifest V3 service worker 中不可用的媒体录制、Blob 和本地附件 ZIP 打包能力。
host permissions <all_urls>：用于用户选择的任意 HTTP(S) 网站、多站点会话、跨域子框架和网络请求诊断，以及多页面截图。静态采集脚本需在页面启动阶段准备好请求包装；只有用户开启的记录范围才保存诊断事件。持续模式仅对用户选择的站点工作。单页 activeTab 临时授权无法覆盖已选站点中新打开的页面、跨域子框架和同时记录的多个标签页。

Remote code / 远程代码
选择“No, I am not using remote code”。扩展执行脚本、压缩库和字体均随扩展包提供；没有远程代码加载器。offscreen.js 的附件 fetch 限制为本地 data: 或 blob: URL。记录网页自身的请求不等于扩展从网络下载代码执行。

Data usage / 数据用途
明确披露：用户活动、网页内容、网络历史记录（记录范围内的网址与页面活动，不是读取 chrome.history 数据库）。
还可能处理：页面、请求正文、日志、截图、视频、可选业务信息中出现的个人身份信息、个人通信、认证信息、财务/支付信息、健康信息或位置描述。没有设备定位 API；没有独立收集这些信息的功能，但不能保证用户录制的网站里不含它们。敏感字段过滤不能替代披露。
实际勾选应结合后台各类别定义逐项核对；不得全部选择“不收集数据”。对于本地截图、视频和请求正文能包含的敏感类别，需如实披露，不可仅因没有服务器就取消。
用途限于用户请求的故障排查和本地导出；不销售、不用于广告、不用于信用评估或贷款。确认开发者实际运营与此一致后，再完成后台声明。
