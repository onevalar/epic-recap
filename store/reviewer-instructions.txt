Recap 0.4.1 — Review instructions

No Recap account, subscription, backend, or API key is required. The UI is currently in Simplified Chinese. Test on an ordinary HTTP(S) website you control using synthetic, non-sensitive data. Reload pages that were open before installing the extension. Chrome internal pages cannot be recorded.

Manual flow:
1. Open a test website. Open the extension popup and click “单次录制” (single recording). The current page is preselected; video is disabled by default.
2. Click “开始录制” (start recording). Interact with the site. A failed request or console error will appear in the diagnostic record. The toolbar shows recording status.
3. Optionally click “标记问题发生在这里” to add a problem marker.
4. Click “停止录制” (stop). The review page opens automatically.
5. Inspect the report preview. Screenshots, video, and request/response bodies are excluded from the exported report by default; these may have been collected locally during recording.
6. Review included content, explicitly acknowledge the review checkbox, and click “导出 ZIP”. Confirm that the local archive contains the report and only selected attachments.
7. A completed export ends the recording; the popup returns to its two entries. Until then, reopening the popup returns to the unfinished recording, which can also be explicitly discarded. Records are never silently replaced.

Multiple pages and continuous mode:
The single-recording setup page lets the reviewer choose up to four pages. “持续录制” (continuous recording) records selected site origins and keeps only the most recent thirty minutes. Only one of the two modes can run at a time. New eligible tabs may join as slots become available. With “视频（含页面声音）” on, continuous mode records video only for the tab where the user opened the popup (one tab at a time; tabs that join automatically never record video), as five-minute clips of which the last thirty minutes are kept (720p, 10 fps, about 0.8 Mbps), capped at 300 MB. Video pauses when less than 1 GB of disk space remains; event capture continues. “停止录制并导出” stops collection, keeps the thirty minutes before the stop, and opens the review page; exporting ends the continuous recording.

Optional video:
Before a manual recording, enable “视频（含页面声音）”. Start from the tab to be recorded. Additional pages may require their own user action/authorization. This captures tab video and tab audio, not camera/microphone. Stop and explicitly select the video in the review page before export.

Privacy and architecture:
No extension-operated server, analytics, advertisements, automatic AI upload, or remotely executed code. Data stays in browser storage/IndexedDB/memory until the user exports it. Page scripts are installed early for compatibility with page request wrappers, but diagnostic recording is gated on a user-started session. Sensitive text masking is best-effort; screenshots/video require user inspection. See the public privacy policy supplied in the Privacy practices tab.
